Gourti Studio Publisher

A private publishing tool for four original video channels

Gourti Studio Publisher uses YouTube API Services to upload the short videos produced each day by one independent creator to that creator's own YouTube channels. It is not offered to the public and does not access anyone else's data.

The channels it publishes to

All four channels belong to the same owner, who is also the only user of this tool:

DentologieShort, accurate explanations of dental and oral health.
Science Explained VisuallyScience and space facts explained with simple animations.
Mindset Animations3D stickman animations about habits and self-improvement.
StickhouseAn original animated stickman mystery series, one part per day.

What the tool does

  1. The owner signs in with Google once per channel and grants upload access (OAuth 2.0).
  2. Each day, the owner's own production software creates one original video per channel (animation, script writing assisted by AI tools, and computer-generated narration), reviewed against fixed quality rules.
  3. The tool checks the file (format, duration, title, description) and uploads it to the matching channel with the YouTube Data API (videos.insert, thumbnails.set), then records the result in a local report.

Use of Google and YouTube data

  • Scopes used: youtube.upload (upload the owner's videos) and youtube.readonly (confirm which channel was authorized). Nothing else is requested.
  • No viewer data, comments, analytics or other users' data are read, stored or shared.
  • Access tokens stay on the owner's own computer, encrypted in Windows Credential Manager.
  • Access can be revoked at any time at Google security settings; stored data is then deleted within 30 days.
