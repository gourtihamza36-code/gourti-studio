Privacy Policy

Effective date: 12 November 2026

Gourti Studio Publisher ("the tool") is a private publishing tool used by a single independent creator, Hamza Gourti (the owner), to upload original videos to the owner's own YouTube channels. The tool uses YouTube API Services. This policy explains what data the tool accesses, how it is used, stored and shared, how long it is kept, and how access can be revoked and data deleted.

1. Who uses the tool

The tool is used only by its owner. It is not offered to the public, and no other person can sign in to it.

2. Data accessed through YouTube API Services

The tool uses YouTube API Services with two OAuth scopes:

  • https://www.googleapis.com/auth/youtube.upload: to upload the owner's videos and set their thumbnails.
  • https://www.googleapis.com/auth/youtube.readonly: to read the authorized channel's ID and title, so that each video is sent to the correct channel.

The API methods used are videos.insert, thumbnails.set and channels.list (own channel only). The tool does not access viewers' personal data, comments, subscribers, analytics, or any channel that the owner has not explicitly authorized.

3. How the data is used

Channel ID and title are used only to confirm the destination of each upload. Upload results (video ID and link) are written to a local report on the owner's computer. No data is used for advertising, profiling, or any other purpose.

4. Storage and security

  • OAuth tokens are stored only on the owner's computer, encrypted in Windows Credential Manager. They are never written to plain files or logs, and logs automatically mask anything that looks like a token.
  • No data is stored on any server operated by the tool. The tool has no database or cloud service of its own.
  • The only API data kept locally is the authorized channel ID and title and the results of the owner's own uploads. The channel ID and title are re-read from the API at every run, so the stored copy is never older than one day.

5. Cookies and device information

The tool is a desktop program: it does not use cookies, and it does not store, access or collect information on any device other than the owner's own computer. This website does not use cookies or analytics.

6. Sharing

The tool does not sell, share, or transfer any data received from YouTube API Services to third parties. Data is exchanged only with Google/YouTube through the official YouTube Data API to perform uploads requested by the owner.

The same tool also publishes the owner's videos to the owner's own Facebook Pages and Instagram accounts through Meta's official Graph API. No data received from YouTube API Services is sent to Meta or to any other service.

7. Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access stops the tool immediately.
  • When access is revoked, or on request to the contact address below, all stored tokens and all data received from YouTube API Services are deleted from the owner's computer within 30 days.

8. Google and YouTube policies

By using the YouTube features of this tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy). The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes

Any change to this policy will be published on this page with a new effective date.
